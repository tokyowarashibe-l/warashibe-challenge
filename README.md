# わらしべ東京 / Straw Millionaire Tokyo

**ゼロから¥100Mへ。AIと共に価値を積み上げる挑戦。**

## 概要

古典的な民話「わらしべ長者」をデジタル時代に再現。初期投資ゼロから、
コード・デザイン・コンテンツ・AIを駆使して価値を交換・増幅しながら
1億円相当の資産形成を目指すプロジェクト。

## 戦略

1. **ゼロからのスタート** — スキルとAIだけが資産
2. **価値の交換** — デジタルプロダクト・サービス・コンテンツを提供
3. **継続的成長** — AIエージェントによる戦略・制作・分析の自動化

## 技術スタック

- GitHub Pages — ホスティング
- HTML/CSS/JS — フロントエンド
- Python — CLIツール・自動化
- Hermes Agent — AIオーケストレーション
- macOS + Ollama — ローカルAI実行環境
